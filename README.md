# Ghunt Cold Coffee Co. (formerly Theka Coffee)

Product website for **Ghunt**: single-estate Arabica cold brew, fresh for 72 hours.

- Live site: https://gamegod2211.github.io/ghunt-coffee/
- QR on the bottle opens: https://gamegod2211.github.io/ghunt-coffee/?scan=1
- QR files: `qr/ghunt-qr.png` (QR only), `qr/ghunt-qr-card.png` (printable label), `qr/ghunt-qr.svg` (vector)

The live freshness clock counts down 72 hours from **12 Nov 2026, 12:00 AM IST**.
To use a different start time, add `?brewed=2026-11-12T00:00:00%2B05:30` to the URL.
